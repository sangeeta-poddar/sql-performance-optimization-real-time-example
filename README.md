# SQL Server Authorization Framework Performance Optimization
### Summary
This repository showcases a real-world SQL Server performance optimization project involving a complex authorization framework used in a multi-tenant enterprise application.
## Key Challenges
-	Nested stored procedures
-	Complex authorization joins
-	Large authorization datasets
-	Extensive use of table variables
-	OR-based filtering conditions
-	Poor query plan stability
## Optimization Techniques
-	Execution plan analysis
-	Stored procedure refactoring 
-	Dynamic SQL generation
-	Indexed temporary tables
## Results 
Metric	Improvement
- Execution Time	Reduced from 3–4 minutes to 15–30 seconds
- Logical Reads	Reduced by approximately 80%
- CPU Utilization	Significantly reduced
- Dashboard Performance	Near real-time response
